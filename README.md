# CatSnap App 🐱

A simple HTML-based cat photo app built as part of the [freeCodeCamp Responsive Web Design Certification](https://www.freecodecamp.org/learn/2022/responsive-web-design/).

## Features
- Uses semantic HTML elements
- Includes headings, links, images, lists, and forms
- Form inputs like text fields, checkboxes, and submit button
